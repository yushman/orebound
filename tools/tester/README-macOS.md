# Orebound — тестовая сборка (macOS)

Сборка не подписана (ad-hoc) и не нотаризована. Версия и коммит показаны внизу экрана итогов вылета.

## Первый запуск

1. Распакуйте архив, перенесите `Orebound.app` куда удобно (например, в «Программы»).
2. Правый клик по `Orebound.app` → «Открыть» → «Открыть» в диалоге.
3. Если macOS всё равно блокирует запуск, в Терминале: `xattr -dr com.apple.quarantine Orebound.app`.

## Управление

Клавиатура и мышь:
- A / D — поворот; W — тяга; S — мягкое торможение.
- Space (зажать) — ускорение времени.
- Shift — синхронизация с ближайшим телом / носителем.
- ЛКМ — луч, ПКМ — сбор; прицел — курсор мыши.
- X — сброс груза; R — перекладка груза; T — вызов буксира.
- `+` / `-` или колесо мыши — масштаб.
- Enter — следующий вылет (на экране итогов).
- F1 — панель настроек и пресетов.

Геймпад:
- Левый стик — курс; правый стик — прицел луча.
- RT — тяга; LT — мягкое торможение; A — ускорение времени / следующий вылет.
- RB — луч; LB — сбор; B — сброс груза; X — перекладка; D-pad вниз — буксир.
- D-pad влево/вправо — масштаб.
- Нажатие левого стика — синхронизация.

Форсаж (boost) работает только при выключенном ускорении времени: откройте F1 и снимите галочку «time warp (Space)».

## Где лежат файлы

- Телеметрия (по JSON на вылет): `~/Library/Application Support/Godot/app_userdata/Orebound/telemetry`
- Сохранённые пресеты: `~/Library/Application Support/Godot/app_userdata/Orebound/presets`

## Протокол тестирования пресетов

1. Откройте F1, выберите пресет в списке и нажмите Load.
2. По 2 вылета на пресет: первый — привыкание, второй — оценка. Порядок пресетов может отличаться у разных тестеров, не подглядывайте в параметры.
3. После каждого пресета заполните анкету 1–5:
   - «понятно, куда тянет» (читаемость);
   - «хотелось лавировать, а не пробиваться силой»;
   - «ошибки ощущались заслуженными» (честность).
4. Дополнительные вопросы (гейт 1):
   - Что вы заметили раньше — звук или картинку?
   - Понятно ли по экрану, хватит ли топлива вернуться?

## Что прислать

- Папку `telemetry` целиком.
- Заполненную анкету.
