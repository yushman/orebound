# autoload

Global singletons registered in `project.godot`.

- `GravityField` is the pure field math: `accel(pos, t)`, `potential(pos, t)`, `body_pos(i, t)` depend only on their arguments and `Tuning.field` (read on each call, no cache, no node state), so any `t` can be queried. Time is `tick` (int, +1 per `_physics_process`); `DT = 1/60` is the one fixed step, `time_at(n) = n / 60.0` (any tick, used by prediction) and `time() = time_at(tick)`.
- Per body g(r) = k·M / (r^p + ε), p per body; ε is only in g; Φ is the antiderivative at ε = 0, so −∇Φ ≈ accel only away from body cores (p = 2: −kM/r; |p−1| < 1e-4: kM·ln r; else −kM·r^(1−p)/(p−1)). Moon pull (`influence_radius` R > 0) fades by smoothstep to 0 over [R, R·(1+`fade_width`)]; Φ in the fade zone is a fixed-sample numeric integral.
- `body_pos(i, t)`: circular orbit `parent pos + orbit_radius·(cos, sin)(phase + angular_speed·t)`; `parent = -1` is the origin.
- `accel_of(i, pos, t)` is the fade-weighted pull of body i; `accel` is the sum of `accel_of`. `dominant(pos, t) -> int` is the body with the largest `|accel_of|` (the brake reference, via `ShipFlight.reference_body`). `body_vel(i, t)` is analytic: parent's `body_vel` + `orbit_radius·angular_speed·(-sin a, cos a)`, zero for the planet. `circular_speed(i, pos, t) = sqrt(r_i·|accel_of(i, pos, t)|)` with `r_i = |pos - body_pos(i, t)|` (only body i's pull; 0 at its center); used by brake and by the `Ship` spawn.
- `Tuning.field` is a `FieldParams` Resource (`k`, `eps`, `fade_width`, `bodies: Array[BodyParams]`); `BodyParams` has `mass`, `p`, `influence_radius` (0 = unlimited), `parent`, `orbit_radius`, `angular_speed`, `phase`. Default is built in code: planet (p = 1, origin) and 2 moons (p = 2).
- `Tuning.ship` is a `ShipParams` Resource (`class_name`, `@export` vars), default built in code: `thrust_accel` 600, `boost_accel_mult` 2.5, `turn_accel` 12 (rad/s²), `spin_damping` 4 (1/s), `heading_gain` 30, `fuel_per_dv` 0.001, `boost_fuel_mult` 3.5, `brake_accel` 200 (1/3 of thrust), `brake_fuel_mult` 1.25, `spawn_radius` 600 (outside the moon2 orbit plus fade), and int prediction params `predict_short_steps` 180 (3 s), `predict_full_steps` 1800 (30 s), `predict_every` 4 (ticks between line recomputes). Values are placeholders for tuning.
- `Telemetry` is still an `extends Node` stub without logic.
