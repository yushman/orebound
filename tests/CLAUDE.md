# tests

GUT suite, run headless (command in root `CLAUDE.md`). Tests that swap `Tuning.field` while a `Prediction` line may be running do it under `Tuning.lock` (the `_set_field` helper in `test_run_scene.gd`, `test_well_view.gd`, `test_ship_prediction.gd`). Tests that change `Tuning.field` / `Tuning.ship` / `Tuning.planet` / `Tuning.picture` restore them (and `Telemetry` when a regenerate writes it); tests that run `ShipFlight` / `ShipPrediction` where asteroids or boulders would interfere pin `asteroids_per_band = 0` and `ring_boulders_per_chunk = 0` (saved / restored `Tuning.planet`) and set `Tuning.picture` by hand (a ringed ambient picture would add boulders and the band drag; `test_run_scene.gd` leaks one, tech-debt #71); fixtures that need the stationary матка pin `carrier_patrol_speed = 0` (the default 40 makes the carrier patrol its orbit in the frame, so fixed-point `(rc, 0)` pins and carrier-sync tests pin the knob to stay meaningful); saves go to `user://`, never `res://presets`. Flight tests on small toy fields (inside the default `planet_surface_radius`) zero `atmosphere_drag` / `atmosphere_damage` or shrink the radii, since the default atmosphere and crash rule treat them as inside the planet.
