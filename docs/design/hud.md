# HUD вылета

Термины — [../glossary.md](../glossary.md). Управление — [controls.md](controls.md),
стиль — [../presentation/visual-style.md](../presentation/visual-style.md), звук —
[../presentation/audio.md](../presentation/audio.md).

## Правило

**Всё, что можно показать в мире, — в мире. На экран — только то, что нельзя
увидеть на корабле.** Звук дублирует критичное. Базовый экран — 1280×800
(16:10, как у Steam Deck; Deck — вторичная платформа, D34).

Уже в мире (не в HUD):
- короткая линия предсказания (≈ 10–20 с) — всегда;
- шеврон скорости: на постоянном расстоянии от корабля по вектору скорости, число |v| рядом, скрыт ниже 1 u/s ([D38](../decisions.md), M10 в [stage1-week3.md](../production/stage1-week3.md));
- шеврон скорости у ориентира синхронизации: тот же шеврон, но по собственной скорости объекта (то, к чему корабль стянется при синхронизации), с числом |v|; только на близком зуме, у неподвижного ориентира скрыт (O86);
- контур ориентира синхронизации дрейфа;
- цвет запаса возврата: стрелка к матке за экраном, контур самой матки в кадре
  (D36);
- нагрев двигателя — свечением сопла (D36);
- контейнеры груза на корпусе;
- свечение атмосферы;
- граница буксира — отдельная окружность границы низа среднего яруса.

## Вопрос игрока → где ответ

| Вопрос | Где ответ |
|---|---|
| Хватит ли топлива на возврат? | цвет запаса возврата (стрелка к матке; в кадре — контур матки) + звук при смене + **полоса энергии в рамке запаса** + полоса запаса возврата под ячейками бака |
| Что в трюме, сколько места? | **полоса ячеек трюма** + общая масса; контейнеры на корпусе |
| Где я в колодце? | **свечение атмосферы** в мире + **шкала колодца** сбоку; при пересечении яруса — письмо-предупреждение в почте (появится вместе с почтой); цветов ярусов в мире нет |
| Цел ли корпус? | сегменты корпуса + свечение повреждений на корабле |
| Что по контракту? | строка контракта в углу |
| Где матка, где обломки за экраном? | стрелки у края экрана |
| Можно ли перерабатывать? | значок «стабильная орбита» |
| Доступен ли буксир? | значок буксира |
| Готов ли сканер? | кольцо сканера |
| Что-то летит на меня? | короткий сигнал со стороной в стерео + предупреждение «удар» / «комета» |

## Три главных элемента

### 1. Полоса энергии: ячейки бака + полоса запаса возврата + рамка состояния
- Ячейки бака: тип — цветом и узором, ячейка заполняется непрерывно; полная
  ячейка обведена.
- Полоса запаса возврата — тонкая штрихованная красная полоса под ячейками
  бака от левого края (ячейки, сгорающие последними): длина — энергия
  `max(одна топливная ячейка, «нужно» на подъём отсюда)`. Растёт сама, когда подъём дорожает.
- Рамка вокруг всей полосы: энергии больше запаса — спокойно; осталась только
  зона запаса — жёлтый; ниже «нужно» — красный + сигнал приборов.
- Пара к цвету стрелки к матке — запасу возврата
  ([flight.md](flight.md), [hold-and-fuel.md](hold-and-fuel.md)).

### 2. Полоса ячеек трюма + общая масса
- Под полосой энергии.
- Рамка вокруг ячейки трюма, которая уйдёт при сбросе (выбранная короткими нажатиями X / B, по умолчанию самая тяжёлая); видна всегда, пока трюм не пуст; бак без рамки.
- Аварийный сброс гасит ячейку самой тяжёлой руды и уменьшает «нужно» (полоса запаса сжимается к одной ячейке).
- Переработка схлопывает 4 ячейки в 1 (3 льда + добавка → топливо).

### 3. Вертикальная шкала колодца
- Сбоку экрана.
- Ярусы — сегментами; сверху матка, снизу кромка атмосферы (красная).
- Линия границы буксира.
- Маркер корабля; отметка глубины контракта.
- Значки обломков: своих и предшественника (на «Горне»).
- **Сегменты пропорциональны долям перепада потенциала** (D30) — шкала
  показывает цену подъёма, а не расстояние.

## Второстепенное

- **Сегменты корпуса** рядом с трюмом (+ свечение повреждений на самом корабле).
- **Строка контракта** в углу — кратко.
- **Значок буксира:** доступен / расходник ×1 / недоступен; меняется на границе
  буксира вместе с предупреждением.
- **Значок «стабильная орбита»:** можно перерабатывать; при первом появлении —
  подсказка R.
- **Стрелка к матке** — цвет показывает запас возврата: обычная → жёлтая →
  красная; линии запаса возврата в мире нет (D35). **Матка в кадре** — стрелку
  заменяет подсвеченный цветом контур самой матки (D36). При смене цвета —
  предупреждение: звук + короткий текст.
- **Стрелки за краем экрана:** обломки — мигают в такт
  маяку и слабеют по мере сгорания. Руда стрелками не показывается — её находит
  сканер.
- **Предупреждения** — коротким текстом вверху по центру на 2–3 с, всегда со
  звуком. Типы: граница буксира, атмосфера, смена цвета запаса возврата, удар,
  комета.

## Раскладка

```
┌────────────────────────────────────────────────┐
│ контракт: 6/8 редкой          [ПРЕДУПРЕЖДЕНИЕ] │
│                                            ┌─┐ │
│                                            │М│ │ ← матка
│                                            │1│ │
│                 (корабль)                  │2│ │ ← граница буксира
│                                            │3│ │ ← маркер корабля
│  ← матка                                   │4│ │
│                                            └─┘ │ ← кромка атмосферы
│        [топливо ▮▮▮▯ в рамке]       буксир ⚓  │
│        [трюм ▥▥▥░░░ · масса 54]    орбита ◯   │
│        [корпус ■■■□]                           │
└────────────────────────────────────────────────┘
```

Критичное — внизу по центру, рядом с кораблём; шкала колодца — сбоку; контракт и
предупреждения — вверху.

## Режим без интерфейса

Прячет всё, кроме предупреждений. Для медитативной игры, скриншотов и трейлера.

## Доступность

- **Цвет — не единственный носитель смысла:**
  - узоры у ячеек трюма (топливо полосатое, лёд точечный и т. д.);
  - значок + звук у предупреждений;
  - запас возврата у стрелки к матке — не только цвет: дублируется звуком и
    коротким текстом при смене цвета.
- Масштаб интерфейса.
- Требования Steam Deck к размеру текста — сверить.

## Чего не будет

- Чисел скорости и высоты.
- Мини-карты колодца.
- Постоянного радара руды.
- Отдельной шкалы бака.
- Шкалы перегрева — нагрев виден свечением сопла и слышен (D36).
- Таймера вылета.
- Кредитов и задолженности в вылете.

## Порядок по этапам

| Этап | Что |
|---|---|
| **Прототип** | полоса энергии (ячейки бака + рамка запаса), полоса запаса возврата под баком, полоса трюма с массой, шкала колодца, сегменты корпуса, стрелка к матке, текстовые предупреждения. В анкету гейта 1 — «понятно ли по экрану, хватит ли топлива вернуться?» |
| **Срез** | значки буксира и стабильной орбиты, строка контракта, стрелки обломков, кольцо сканера, режим без интерфейса, узоры для дальтоников |
| **EA** | интерфейс Отрыва (точки манёвров, состояние деталей, нагрев радиаторов), масштаб интерфейса |

## Открытое

См. [../production/open-questions.md](../production/open-questions.md): числа на
полосе энергии («24 / 21») или только рамка; читается ли полоса запаса как «сколько нужно, чтобы вернуться»; индикатор скорости относительно
ориентира синхронизации; интерфейс Отрыва (отдельно, к EA).

## Отклонённые варианты

- **Числа скорости и высоты** — читаются траекторией и шкалой колодца.
- **Мини-карта колодца** — шкала колодца и свечение атмосферы в мире; цветов ярусов нет (D37).
- **Постоянный радар руды** — руду находит сканер.
- **Отдельная шкала бака** — топливо в трюме; энергия — одна полоса ячеек с рамкой.
- **Таймер вылета** — часы вылета — топливо и масса.
- **Кредиты и задолженность в вылете** — это банк, в хабе.
- **Шкала колодца по расстоянию** — показывала бы не цену подъёма.
