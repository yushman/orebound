## Валюты и рычаги

Две валюты, четыре точки их входа и выхода.

### Вход

| Источник | Ресурсы | Кредиты |
|---|---|---|
| Майнинг (астероиды / кольца / спутники) | ✅ | — |
| Убитые враги (подбор) | ✅ | — |
| Найденные технологии | ✅ (как ресурс) | — |
| **Выполнение контракта** | — | ✅ **премия** |
| Продажа ресурсов на рынке | — | ✅ **с дисконтом** |

### Выход

| Покупка | Ресурсы | Кредиты |
|---|---|---|
| Апгрейд корабля (базовый) | ✅ | — |
| Апгрейд оружия / майнер-тула (базовый) | ✅ | — |
| Апгрейд корабля (продвинутый) | ✅ | ✅ |
| Ремонт корабля после смерти | — | ✅ |
| **Новый корабль** | — | ✅ |
| Покупка ресурсов на рынке | ✅ **с переплатой** | — |
| Переезд хаба | — | ✅ |

## Рынок

Рынок — **сервис, а не ломбард**: полезен в обоих направлениях, но всегда с
издержкой. Это делает его «выключателем безопасности»: если игрок не хочет
рисковать — рынок даёт выход, но за наценку.

```
ПРОДАЖА:  цена_продажи = базовая_цена × (1 − дисконт)        // дисконт < 0%
ПОКУПКА:  цена_покупки = базовая_цена × (1 + наценка)         // наценка > 0%
```

### Динамика цен

Базовая цена ресурса — функция от:

- **Тира ресурса** (базовый / средний / редкий / уникальный).
- **Планеты-цели**: дорогие ресурсы из дальних систем стоят дороже.
- **Хаба**: каждый хаб — свой рынок со своим спредом. Это даёт смысл переезду
  и создаёт настоящие торговые маршруты.
- **Времени / прогресса**: спрос на ресурсы растёт с открытием новых апгрейдов.

Спред (дисконт/наценка) должен быть достаточно широким, чтобы рынок был
заметным решением, но не настолько, чтобы ломал экономику.

> **Самопроверка:** если игрок может бесконечно фармить на одном дешёвом
> ресурсе, продавать его дорого и покупать всё остальное дешевле — экономика
> сломана. Спрос и предложение по каждому ресурсу должны быть **сбалансированы
> по источникам и стокам**.

## Контракты: кредитная премия

Цена контракта — главный источник кредитов. Значит, цена контракта должна быть
**сопоставима со стоимостью апгрейда**, ради которого игрок рискует.

```
премия = базовая_ставка_контракта × множитель_сложности × срочность
```

Ключевые свойства:

- **Кредиты даются только за выполнение.** Провал не даёт ничего — риск чистый.
- **Несколько контрактов одновременно** дают повышенную премию за суммарное
  выполнение (надбавка за «пакет»).
- **С ростом системы растёт и ставка**, иначе игру перестаёт быть интересно
  проходить заново.

## Тиры ресурсов

| Тир | Где встречается | Роль |
|---|---|---|
| Базовый | Астероиды у хаба | Топливо апгрейдов, ремонт не покрывает |
| Средний | Астероиды дальше, спутники | Основные апгрейды |
| Редкий | Кольца, мелкие спутники | Дорогие апгрейды, крейты |
| Уникальный | Глубокие зоны, инопланетные сайты | Только для покупки новых кораблей / ключевых технологий |

> Каждый тир должен быть **необходим** — если редкий ресурс можно заменить
> эквивалентом из базовых, прогрессия теряет ритм.

## Корабли

- **За кредиты покупается новый корабль.** Это «потолок» кредитной экономики.
- Корабль — это не «лучший вариант», а **другой профиль**:
  - грузовой (большой трюм, слабое оружие) — для спокойного фарма;
  - разведчик (быстрый, слабый трюм) — для опасных вылетов;
  - боевой (оружие, средний трюм) — для зачистки.
- Как и стартовые хабы, корабли должны **отличаться по геймплею**, а не по
  числу характеристик.

## Модель баланса (связи, не числа)

Правильный баланс — это набор **согласованных отношений**, а не набор
констант:

```
ПОТЕРЯ СМЕРТЬЮ      ≈  стоимость 1–2 вылетов
РЕМОНТ ПОСЛЕ СМЕРТИ ≈  1–2 гарантированных контракта   (иначе петля долга)
БАЗОВЫЙ АПГРЕЙД     ≈  1 вылет по планете-цели          (заметный, не разорительный)
УЛУЧШЕННЫЙ АПГРЕЙД  ≈  2–3 вылета                      (требует накопления)
НОВЫЙ КОРАБЛЬ        ≈  15–30 вылетов                   (долгосрочная цель)
ПРЕМИЯ КОНТРАКТА     ≈  1–2 вылета по ценности          (выгодно, но с риском)
```

Эти соотношения — **стартовый гипотетический набор** для симуляции, а не
финальные числа. Их нужно проверить прогон-симуляцией в Excel/скрипте
(см. [open-questions.md](open-questions.md)).

### Проверка на петлю долга

Симулятор прогрессии должен проверить:

1. После худшего случая (смерть) есть ли у игрока **путь к восстановлению**.
2. Сколько вылетов до первого нового корабля — не слишком ли много / мало.
3. Не доминирует ли один ресурс (фарм одного тира не выгоднее остальных).
4. Существует ли осмысленная стратегия «медитативный фарм» **и** осмысленная
   стратегия «агрессивные контракты».

## Чего в экономике быть не должно

- **Эксплойта застревания в нише** (где-то в игре есть объект, который можно
  бесконечно добывать быстрее рынка).
- **Ловушки в циклах денег** (премия за контракт > стоимость апгрейда, который
  делает премию легче — бесконечное накопление).
- **Обязательной валюты.** Ни одна валюта не должна быть единственным
  обязательным путём прогресса.
