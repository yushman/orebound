# Верификация фактов из разбора пессимиста

Проверено вручную 20.10.2026. Подтверждено ≠ подтверждено полностью.

## Проверено: совпадения

### Space Outpost Sigma (Steam App 3482440) — ✅ подтверждено, с оговоркой

Описание **совпадает** по всем заявленным признакам: top-down 2D pixel art,
майнинг астероидов, **ньютоновская космическая физика**, дроны, стационарный
аутпост для защиты, торговые корабли, процедурные ран-зоны, «выжить как можно
дольше», теги Roguelite + Casual/Relaxing + Procedural Generation.

**Оговорка, меняющая вывод.** Коммерческая traction:

| | |
|---|---|
| Релиз | 21 апр 2025 |
| Отзывов | **2** |
| Агрегатный счёт | не сформирован («need more user reviews») |
| Цена | €4,99 |

То есть пессимист прав в **дизайнерском** пересечении, но переоценивает **рыночное**
давление: ближайший по механике конкурент продал практически ничего. Поджанр
перенасыщен не по спросу, а по предложению.

**Структурное отличие от нашей идеи (в нашу пользу):** у Sigma аутпост —
стационарная цель, которую нужно защищать; игрок не маневрирует по всей системе
и не выбирает планету-цель. Структура хаб/система/планета отсутствует.

Дополнительно: у Sigma в тегах **Time Manipulation** и **Casual/Relaxing** —
то есть автор сознательно пошёл в «спокойную» сторону, а не в рогалик.

### Star Mining Co. (Steam App 2584800) — ✅ подтверждено

Action Roguelike + Roguelike Deckbuilder, **Perma Death — официальный тег**
(«failure to make a profit for Star Mining Co. will terminate your contract, and
YOU, permanently!»), бурение астероида от корки к ядру кастомизируемой
сверхсверлой, апгрейды за долю прибыли, процедурные астероиды.

| | |
|---|---|
| Релиз | 21 апр 2025 |
| Отзывов | 29 (82% positive) |
| Цена | €8,79 |

Solo dev, есть демо. **Отличие от нашей идеи:** здесь сверло, а не корабль с
инерцией; нет гравитации, нет хаба, нет выбора цели вылета. Структурно
конкурент не пересекается — пересекается только тон («карьер → прибыль →
перма-смерть»).

## Не проверено

Остальные App ID (Void Harvest 3397460, Void Miner 3772240, Orbit Newton,
Gravity Game 3970750, Cosmic Quarry) и утверждение про «7–8 конкурентов» не
перепроверялись. App ID двух ключевых игр совпали, что повышает доверие к
остальным, но не заменяет проверку.

Также не проверены: «45–55% женская аудитория у cozy» и «+8–15% churn от
доп. валютного экрана». Первое — вторичные источники, второе помечено самим
пессимистом как перенос из мобильных F2P. **В цифрах не использовать.**

## Что из этого следует

1. **Референс по описанию — действительно Space Outpost Sigma, а не Ship Miner.**
   Это меняет позиционирование: Ship Miner — референс по тону и арту, но
   структурное совпадение у Sigma.
2. **Плотность поджанра реальна, но спрос не подтверждён.** Два ближайших
   конкурента вышли в апреле 2025 с 2 и 29 отзывами. Это аргумент не против
   идеи, а против ожиданий по продажам в поджанре.
3. **Дизайн-пространство не занято.** Структура «хаб → система → планета-цель →
   вылет с гравитацией» не воспроизведена ни в одной из проверенных игр. Это
   подтверждает «главную силу» пессимиста.
4. **Проблема упаковки, а не идеи.** Проблемы п. 2.1–2.9 (медитативность,
   петля долга, двойная валюта, отсутствие вин-кондиции) остаются в силе —
   они про дизайн, а не про рынок, и верификация их не отменяет.
