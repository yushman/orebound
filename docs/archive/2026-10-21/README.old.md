# OREBOUND

Экстракшн-рогалик про добычу ресурсов в космосе. Top-down 2D, лавирование между
гравитациями планет, спутников и астероидов, контракты на вылеты, хаб-структура
с переездом между звёздными системами.

Референс по стилистике и тону: **Ship Miner** (Steam App ID 3113690, arielcoppes).
Отличия от референса — в разделе «Чем мы отличаемся».
