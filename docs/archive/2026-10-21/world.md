# Мир: хаб, звёздные системы, перелёты

## Три уровня структуры

```
ХАБ-ПЛАНЕТА          ← где живёшь, торгуешь, чинишь корабль, берёшь контракты
  └── ЗВЁЗДНАЯ СИСТЕМА ← карта с несколькими планетами-целями
        └── ВЫЛЕТ      ← один планетный сектор вокруг конкретной планеты
              ├── кольца
              ├── астероиды
              └── мелкие спутники
```

## Хаб

- Хаб — **планета**, а не станция в космосе. Поверхность, база, ангар, рынок,
  отправка вылетов.
- На старте игрок **выбирает одну из трёх стартовых планет**.
- Позже можно **переехать** на другую планету-хаб. Переезд — это не «телепорт»,
  а решение: новая база, новый регион, новые цены и новые контракты.
- Хаб — единственное безопасное место. Здесь нет врагов и нет смерти.

### Что даёт выбор стартовой планеты

Три стартовые планеты должны отличаться не косметикой, а **профилем игры**:

| Планета | Профиль | Что даёт |
|---|---|---|
| | | |
| | | |
| | | |

> ТЗ: конкретные отличия зафиксировать в дизайне. Минимум — разный набор
> доступных типов контрактов и разный диапазон цен на рынке, чтобы стартовый
> выбор влиял на экономику, а не на погоду в окне.

### Переезд между хабами

Переезд должен быть **осознанной платой за новый профиль**:

- перевезти оборудование (стоит кредитов);
- часть апгрейдов корабля может быть несовместима с новой базой;
- новый хаб даёт доступ к другим звёздным системам.

Обоснование: иначе хаб — это просто спавн, и переезд теряет смысл.

## Звёздные системы

- Есть **несколько звёздных систем**. Каждая — карта с планетами.
- В системе видны планеты с разными параметрами: богатство кольцами, размер,
  количество спутников, опасность.
- Планета в системе — это **цель вылета**: «полететь к планете X за ресурсом Y».
- **Освоение системы** — условие для перелёта в следующую систему. Что считается
  освоением (выполнено N контрактов / добыт редкий ресурс / зачищена система),
  определить в дизайне.

### Перелёт между системами

- Происходит через хаб (или напрямую со станции перелётов на хабе).
- Новая система = новые планеты, новые типы ресурсов, новая сложность.
- Старые системы остаются доступными — прогресс не отбирает доступ.

## Вылет: устройство сектора

Каждый вылет — инстанс вокруг одной планеты-цели.

```
                    КОЛЬЦА
              (основной источник редких)
                   ╭───────╮
      астероиды ●──┤ ПЛАНЕТА├──● астероиды
                   ╰───────╯
              ●  спутник      спутник  ●
          мелкие спутники, поле обломков, «карманы» с ресурсом
```

### Источники добычи

| Источник | Что даёт | Характер |
|---|---|---|
| **Кольца планеты** | Редкие и самые дорогие ресурсы | Открытое пространство вокруг планеты, хорошо видно, но и врагов видно |
| **Астероиды** | Базовые и средние ресурсы, изредка технологии | Главный объём добычи. Своя гравитация |
| **Мелкие спутники** | Средние и редкие ресурсы, техники | Более опасные, чем астероиды: больше гравитация и меньше места |
| **Обломки / карманы** | Случайные находки, компоненты | Награда за любопытство |

> Все астероиды, спутники и кольца **процедурно генерируются** при каждом вылете.

## Гравитация

Это центральная механика, а не украшение.

- У **каждой** планеты, спутника и крупного астероида — **собственный центр
  притяжения и своя сила**.
- Корабль втягивается в зону притяжения. На высокой скорости по прямой он
  может врезаться в планету или спутник.
- Гравитация планеты не отменяется, когда игрок улетел с орбиты — прецессия и
  «сваливание с орбиты» делают управление постоянным, а не разовым.
- Кольца — зона со слабой стабилизирующей силой: там легко удерживать позицию,
  но легко сорваться.

### Зачем это нужно игроку

- **Навык:** лавировать между центрами притяжения — это управление с инерцией.
- **Тактика:** можно использовать притяжение астероида, чтобы ускориться и
  уйти от пиратов, или наоборот — дать кораблю упасть на астероид, чтобы
  сорвать преследователя.
- **Риск:** добыча рядом со спутником — это всегда работа с гравитацией, а не
  «подлетел и пробурил».

## Пирамида контента (что нужно произвести)

| Уровень | Кол-во | Требуемый объём контента |
|---|---|---|
| Стартовые хабы | 3 | Набор рынка, контрактов, декора, услуг |
| Звёздные системы | 2 на старте | Карта, планеты, распределение ресурсов |
| Планеты-цели на систему | 3–5 | Параметры + уровни сложности |
| Спутники | 2–4 на планету | Параметры гравитации, ресурсной базы |
| Типы ресурсов | 6–8 | Визуал, ценность, где встречается |
| Кредитные контракты | 3 типа (см. [roguelike.md](roguelike.md)) | Шаблоны целей |
| Типы врагов | 3–4 (пираты / кометы / астероиды / инопланетяне) | Поведение, волны, вознаграждение |
