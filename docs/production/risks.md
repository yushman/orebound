# Риски

Термины — [../glossary.md](../glossary.md). Сводный реестр; подробности — в
документах по ссылкам.

## Дизайн и исполнение

| Риск | Чем закрываем | Где проверяем |
|---|---|---|
| **Гравитация нечитаема** (главный риск по обоим разборам) | ореол с сжимающимися кольцами у лун, ярусы, запас возврата, звук приборов | гейт 1 |
| **Предсказание траектории не получится** — от него зависят валидатор и Отрыв (в вылете — только короткая линия, D35) | короткая линия в неделе 1′ | этап 1 |
| **Предсказание расходится с полётом** | один `GravityField`, тот же шаг и dt, строго фиксированный шаг 60 Гц ([prototype-tech.md](prototype-tech.md)) | DoD этапа 1 |
| **Энергетическая оценка запаса возврата врёт** | настраиваемый коэффициент запаса; полная симуляция — только по данным плейтеста | гейт 1 |
| **32-битная точность далеко от начала координат** | умеренный масштаб колодца; карта системы для Отрыва — отдельная сцена со своим масштабом | этап 1, этап 5 |
| **Шум колец ореола при отдалении** | кольца только в зоне влияния луны, сглаживание `fwidth`, плотность колец — ползунками | этап 1 |
| **Производительность колец** | `MultiMeshInstance2D`, столкновения только рядом с кораблём | этап 1 |
| **Форсаж вытесняет лавирование** | форсаж в 3–4 раза дороже, масса удорожает | метрика < 30–40% топлива, гейт 1 |
| **Игрок не планирует запас на подъём** в едином трюме | запас возврата, буксир, комплектация по умолчанию; откат на отдельный бак | A/B, гейт 1 |
| **Стыковка раздражает** | большой радиус захвата, медленная матка; запасной хаб — станция | < 15–20 с, гейт 1 |
| **Без боя скучно** | среда (атмосфера, мусор, кометы, масса) | решение по пиратам на гейте 2 |
| **Безопасный фарм льда выгоднее глубины** | доход/мин растёт с глубиной (модель: середина 2,3×, низ 4,3× льда — требует перекалибровки, D30) | симулятор, этап 2 |
| **Середина на шлюпке слишком выгодна** (2,3× выше границы буксира) | конфискация при буксире, трюм шлюпки, плотность среднего тира | симулятор, плейтест |
| **Петля долга** | служебная шлюпка, подработка, долг за аванс ≤ 3–4 ледяных вылета | симулятор, гейт 2 |
| **Дилемма добавки не работает** | баланс количества средней руды | доля сжигания 30–60%, гейт 2 |
| **Вырожденная генерация** | правила честности, валидатор | этап 2 |
| **Онбординг на «Инее» проверяется только в EA** (срез — на «Ободе») | «Иней» строго мягче «Обода» | плейтест EA |
| **Демо суетнее начала EA** («Обод»: кольца, три луны, много мелких объектов) | спокойный верхний ярус «Обода», ограничения генерации в первых сменах | гейт 2 |
| **Перегрузка новичка** | первые смены, шлюпка; форсаж и аванс — во второй час при необходимости | гейт 2 |
| **Рутина добора ресурсов под детали Отрыва** | ориентир ≤ 4–6 вылетов на деталь | симулятор, плейтест EA |
| **Игрок всё продал и злится, когда открылись рецепты** | рецепты видны с момента находки чертежа | плейтест EA |
| **Сцена системы для Отрыва** — свой масштаб, камера, баланс | та же функция гравитации; точечные массы; отдельная сцена | этап 5 |
| **Ожидание окна отрыва скучно / окна слишком редки** | вне окна стартовать можно; частота окон — гипотеза | симулятор, плейтест EA |
| **Ускорение времени пропускает сближения** | автоматический сброс в ×1 перед сближением | этап 5 |
| **Отрыв превращается в «следуй подсказкам»** | исполнение требует точности (тайминги, повороты); план верен только при идеальном исполнении | плейтест EA |
| **Повторяемость Отрыва в главах** | разные конфигурации систем | после EA |

## Производство

| Риск | Чем закрываем |
|---|---|
| **Выгорание одного разработчика** | гейты с результатом и правом остановиться |
| **Расползание скоупа** | правило: всё вне списка этапа — в «После EA» ([scope.md](scope.md)) |
| **Шейдеры — новая область** | закладывать время, ограничение по времени |
| **Звук затягивает** | сначала функциональные звуки |
| **Стиль холодный / абстрактный** | свечение, тёплая матка, иллюстрации хаба, звук |

## Рынок

| Риск | Чем закрываем |
|---|---|
| **Сценарий Super Motherload** (игра приятная, аудитории нет) | позиционирование через уникальную механику; планировать под нижний сценарий продаж ([../research/market.md](../research/market.md)) |
| **Мало вишлистов после Next Fest** | решение после фестиваля: урезанная EA или остановка |
| **Ожидание сюжета из-за сравнения с Dredge** | не обещать сюжет |
| **Тег Relaxing даёт плохие отзывы** | ставить только по данным демо |
| **Враждебность к ИИ-контенту** | ИИ только в иллюстрациях хаба; капсула из кадра игры; раскрытие |
| **Визуальное сходство с Ship Miner** | стиль ореола и колец, не пиксель-арт |
