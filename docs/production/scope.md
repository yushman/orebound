## Вертикальный срез (этап 3)

Полный цикл «матка → вылет → матка» на одной планете. Основа демо.

| Система | Объём |
|---|---|
| Хаб | 3 экрана (Ангар, Контора, Пульт вылета) с простыми картинками; почта списком; склад ресурсов; приветственная записка и первый наряд; брезент в углу ангара (одна картинка + текст подсказки) — намёк на финал; нелепая цена демонтажа; напоминания «мусор не убран» без штрафа |
| Планета | 1 — **«Обод»** ([../design/planets.md](../design/planets.md)), полный колодец: лёд, базовая, средняя, редкая, уникальная руда на дне (загадка: хранится на складе, не продаётся) |
| Генерация | правила честности + валидатор; ограничения для первых вылетов |
| Контракты | 2 типа: заказ + подработка; аванс; оплата за единицу + бонус |
| Рынок | фиксированные цены |
| Топливо | базовая заправка в матке + переработчик на корабле (апгрейд), стабильная орбита не нужна |
| Провалы | буксир до низа среднего яруса (граница фиксирована, предупреждение на границе), гибель = ремонт, служебная шлюпка (гибель — груз изъят, обломков нет, выговор), обломки своих кораблей |
| Корабли | служебная шлюпка + «Рабочий» |
| Апгрейды | 5–7 |
| Угрозы | мелкие объекты, атмосфера, кометы. **Без пиратов** |
| Онбординг | первые смены на верхнем ярусе «Обода» с ограничениями генерации, памятка в почте |
| HUD | + значки буксира и стабильной орбиты, строка контракта, стрелки обломков, кольцо сканера, режим без интерфейса, узоры для дальтоников ([../design/hud.md](../design/hud.md)) |
| Стиль | финальный стиль на одной планете |
| Звук | генеративный фон со слоями по глубине, фон хаба, стыковка, почта, временная мелодия хаба |

## Early Access — глава 1 (этап 5)

Законченная игра с финалом.

| Система | Объём |
|---|---|
| Система | 1 звезда, 1 матка, **3 планеты**: «Иней», «Обод», «Горн» ([../design/planets.md](../design/planets.md)) |
| Карта системы | выбор планеты, индикатор окна отрыва, предсказанная траектория, симуляция маршрута с точками манёвров; сцена Отрыва (часть этого режима) с ускорением времени ×1/×4 |
| Финал | Отрыв: чертёж, стапель, 3 детали по рецептам (Радиаторы, Каркас, Двигатель отрыва), траектория-прогресс, маршрут «Иней» → «Обод» → «Горн» → корона, окна отрыва, повреждение и ремонт деталей, письмо-концовка |
| Контракты | 4 типа: + доставка вниз, + маяк |
| Корабли | 4: служебная шлюпка, «Рабочий», грузовой, разведчик |
| Апгрейды | 12–15 корабельных; 3 апгрейда хаба (сканер прибытия, своя переработка, склад обломков); расходник «разовый глубокий буксир» |
| Топливо | + переработка в хабе за кредиты |
| Хаб | нарисованная сцена ангара, корабль для отрыва под брезентом, почта с текстами |
| Сюжет | обломки предшественника (постоянный объект на малой луне нижнего яруса), чертёж и записи предшественника |
| Угрозы | + **пираты**, только если срез показал, что без боя скучно |
| Звук | тема хаба, трек Отрыва, варианты фона для планет |
| Обвязка | сохранения, настройки, геймпад, проверка на Steam Deck, английский и русский |

## После EA

- Главы 2–3 (новые системы, свои конфигурации для Отрыва).
- Модификаторы планет: приливы лун, тень планеты, звёздные вспышки.
- Повреждения, выбивающие ячейки трюма; сетка трюма с фигурами предметов.
- Страховка.
- Несколько хабов, спред рынка, арбитраж.
- Инопланетяне, зачистка, ко-оп — под вопросом.

## Вырезано

| Что | Почему |
|---|---|
| 3 хаба на выбор, переезд хаба | одна матка на главу; переезд = Отрыв |
| 4 системы × ~20 планет с уникальными спутниками | планета = параметры + генератор |
| Опыт и уровни корабля внутри вылета | наследие рогалика ([../design/failure.md](../design/failure.md)) |
| Open run / contract run | риск регулирует глубина |
| Таймер контракта | часы вылета — топливо и масса |
| Отдельное оружие | инструмент в двух режимах |
| Инопланетяне в EA | скоуп |
| Ко-оп | удорожание баланса ×2 |
| Спред рынка в MVP | без нескольких применений ресурса — налог |
| Ходьба по хабу | скоуп |

## Сравнение с исходной оценкой пессимиста

| | Было | EA |
|---|---|---|
| Хабы | 3 | 1 матка (экраны) |

| Валюты | 2 | 2 |

## Правило

Всё, чего нет в списке этапа, идёт в «После EA».

## Отклонённые варианты

- **1 хаб × 1 система × 3 планеты как MVP без финала** (пессимист) — EA без
  финала; финал Отрыв умещается в этот же объём.
- **Полный продукт к Ship Miner (26.11.2026)** — недостижимо.
- **Пираты в срезе** — самая дорогая система, не проверяет уникальную механику.
