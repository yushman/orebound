# Симулятор экономики

Термины — [../glossary.md](../glossary.md). Модель в числах —
[../design/economy.md](../design/economy.md). Место в плане — [plan.md](plan.md),
этап 2. Все числа ниже — гипотезы.

## Зачем

1. **Ловить арифметические ошибки кодом, а не глазами.** Уже было четыре случая:
   - переработка на корабле «≈ 20 кр» на деле стоила 40 кр;
   - масса сжатого топлива противоречила D5 (переработка сохраняет массу);
   - бюджет деталей Отрыва был завышен в 1,6 раза;
   - эталонные вылеты «поехали» после перехода на лестницу из потенциала (D30).
2. **Отвечать на поведение экономики за 10 часов** у разных игроков: где
   застревают, где скучно, где экономика ломается.

## Четыре слоя

### 1. Калькулятор вылета
- Вход: планета, ярус, корабль, апгрейды; **статистика генератора колодца**
  (ресурсов на ярус, среднее расстояние между полями, ожидаемое время заполнения
  трюма — [well-generator.md](well-generator.md)).
- Подбирает **лучшую комплектацию трюма** с ограничением по топливу.
- Подъём — по формуле потенциала (D30): масса × (потенциал орбиты матки −
  потенциал в точке); вылет ≈ 1,3 × подъём.
- Выход: доход за вылет и в минуту, отношение ко льду, доля трюма под топливом,
  выгодна ли переработка, флаг **«невыполнимо»**.

### 2. Модель исхода
- Вероятности **вернулся / буксир / гибель** по ярусу и навыку.
- Расход топлива относительно идеала (гипотеза): новичок ×1,3, средний ×1,15,
  опытный ×1,0.
- Потери груза: конфискация при буксире 30%, обломки 40%, гибель шлюпки — 100%.
- Вероятности — догадки до прототипа, затем берутся из телеметрии
  ([prototype-tech.md](prototype-tech.md)).

### 3. Стратегии
Простые и именованные:
- **«Спокойный»** — держится верхних ярусов, без авансов;
- **«Жадный»** — идёт как можно ниже;
- **«Расчётливый»** — выбирает лучший ожидаемый доход в минуту с учётом риска;
- **«Контрактник»** — живёт контрактами и авансами.

### 4. Монте-Карло
- Партия от старта (шлюпка, 0 кр) до Отрыва: окна отрыва, провалы, ремонт деталей.
- **1000 партий** на пару «стратегия × навык».

## DoD симулятора

| Проверка | Цель | Откуда |
|---|---|---|
| Время до «Рабочего» | ≤ 45 мин | онбординг |
| Время до финала | 8–12 ч (медиана + p10–p90) | экономика, ориентир главы |
| Восстановление после худшего случая | ≤ 3–4 ледяных вылета | петля долга |
| Ожидаемый доход низ > середина | при 10–20% гибели внизу | «жадность окупается» |
| Доля сожжённой добавки | 30–60% | трюм и топливо |
| Добор на деталь Отрыва | ≤ 4–6 вылетов | финал |
| O37 | «Рабочий» выгоднее шлюпки вскоре после покупки | open-questions |
| «Горн» ×1,6 | окупается с апгрейдами, не на базовом «Рабочем» | планеты |
| Окна отрыва против ремонта | худший ремонт ≤ интервала хорошего окна (O51) | финал |
| Неспешный путь | «Спокойный» доходит до финала | экономика |
| Эталоны выполнимы | нет флагов «невыполнимо» | экономика |

**Чувствительность:** ±20% по каждому параметру, диаграмма-«торнадо». Вероятные
лидеры: полный перепад, масса редкой руды, вероятность гибели внизу.

## Технически

- **Python.**
- **Один JSON параметров экономики**, который читают и симулятор, и Godot
  (`Tuning`, [prototype-tech.md](prototype-tech.md)).
- **Формула потенциала** та же, что в `GravityField`, плюс **тест сверки** обеих
  реализаций на наборе точек.
- Структура:

```
tools/econ-sim/
  config/economy.json
  model.py         # калькулятор вылета
  outcomes.py      # модель исхода
  policies.py      # стратегии
  sim.py           # Монте-Карло
  sensitivity.py   # чувствительность
  report.py        # отчёт
  tests/           # эталонные вылеты — регрессионные тесты
```

- Отчёт — markdown с таблицей DoD (✅/❌), распределениями и «торнадо»; после
  серьёзных прогонов кладётся в `docs/research/`.

## Порядок (≈ неделя в этапе 2)

1. Конфиг + калькулятор + тесты эталонов. Если эталон невыполним — сначала
   правим параметры.
2. Детерминированная партия «среднего игрока».
3. Вероятности, стратегии, Монте-Карло.
4. Чувствительность и отчёт.

## Чего не скажет

- Ощущения.
- Навык — до телеметрии это догадки.
- Поведение людей.

Результат — диапазоны и предупреждения. После прототипа — перепрогон на реальных
данных телеметрии.

## Открытое

- Стартовые вероятности гибели и коэффициенты навыка (предложение: консервативные
  10–20% внизу + чувствительность).
- Формат общего конфига: JSON, читаемый обоими (предпочтительно), против экспорта
  из `.tres`.

См. [open-questions.md](open-questions.md).

## Отклонённые варианты

- **Excel** — ошибки арифметики ловятся глазами, нет Монте-Карло и тестов.
- **Симулятор в Godot** — медленнее итерации; экономика не зависит от движка.
- **Полная симуляция полёта внутри экономики** — избыточно; цена подъёма
  считается формулой потенциала.
- **Обучаемые агенты** — сложно и непрозрачно; хватает именованных стратегий.
