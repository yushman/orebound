## Допущения

- **Один разработчик, примерно полный день.** При частичной занятости сроки ×1,5–2.
- **Движок — Godot 4** (2D-шейдеры, 2D-физика, бесплатный).
- Даты Steam Next Fest, взнос Steam Direct и правила раскрытия ИИ — сверить перед
  планированием ([open-questions.md](open-questions.md)). Обычно Next Fest — в
  феврале, июне и октябре; регистрация закрывается заранее.
- Ship Miner выходит в EA 26.11.2026; выход к нему не планируется.

## Этап 1. Прототип (4–5 недель) → гейт 1

Состав — [scope.md](scope.md); техническая основа — [prototype-tech.md](prototype-tech.md);
управление — [../design/controls.md](../design/controls.md). Первым делом — предсказание траектории.

> **Неделя 1 отклонена (22.10.2026).** Реализация S1–S5
> ([stage1-week1.md](stage1-week1.md)) не прошла ручной плейтест: масштаб,
> камера, планета точкой, тяга. Модель уточнена в D35 «Сектор у планеты»
> ([../decisions.md](../decisions.md)); план переделки кода — не решён.

**Порядок по неделям:**

| Неделя | Работы | Результат |
|---|---|---|
| 1 | `GravityField`, тела на орбитах, корабль (поворот, тяга, тормоз, форсаж), предсказание траектории, панель настройки | линия предсказания совпадает с полётом |
| 2 | колодец с ярусами, атмосфера, шейдер изолиний, кадр стиля, генерация (этапы 1–5 с простыми кольцами без щелей + геометрическая проверка — [well-generator.md](well-generator.md)); HUD: шкала колодца | колодец читается, кадр стиля собран |
| 3 | трюм с массой и объёмом, топливо, лёд и руда, инструмент, мелкие объекты (упрощённый этап 7 генератора: вытянутые орбиты с частотой по ярусу, без комет) и разбивание, аварийный сброс; HUD: полоса энергии с отметкой, полоса трюма, корпус | полный вылет |
| 4 | матка и стыковка, запас возврата, звук, телеметрия, HUD: стрелка к матке и предупреждения, сборка для тестеров (Windows, macOS) | сборка у тестеров |
| 5 | плейтест 3–5 человек, настройка по данным | решение гейта 1 |

**DoD (технический):**
- [ ] Вылет играется от расстыковки до стыковки без перезапуска.
- [ ] Предсказание траектории совпадает с реальным полётом на фиксированном шаге
      60 Гц.
- [ ] Линия запаса возврата меняет цвет по энергетической оценке
      ([prototype-tech.md](prototype-tech.md)).
- [ ] Панель настройки работает, пресеты `.tres` сохраняются и загружаются; A/B —
      пресетами.
- [ ] Телеметрия пишет JSON после каждого вылета по списку из
      [prototype-tech.md](prototype-tech.md).
- [ ] Сборки Windows и macOS розданы тестерам закрытой ссылкой или архивом.
- [ ] Генератор: чистая функция (константы, зерно, номер вылета), зерно в
      телеметрии; этапы 1–5 (простые кольца) и упрощённый этап 7 (мелкие
      объекты); геометрическая проверка; выбор зерна на панели.
- [ ] HUD прототипа по [../design/hud.md](../design/hud.md): полоса энергии с отметкой, полоса
      трюма с массой, шкала колодца, сегменты корпуса, стрелка к матке,
      текстовые предупреждения.
- [ ] Пресеты гравитации П1–П4 переключаются на панели (ползунок p), ярусы заданы
      уровнями потенциала, энергии подъёма совпадают с моделью экономики;
      режим «единый трюм / отдельный бак» переключается.
- [ ] Форсаж, атмосфера (урон + торможение), два режима инструмента работают.
- [ ] Управление по схеме controls.md на клавиатуре и геймпаде; стыковка
      автоматическая; сброс и буксир — долгим нажатием.
- [ ] Метрики пишутся в лог: доля топлива на форсаж и на тормоз, частота тормоза,
      отключение автомасштаба, случайные нажатия сброса и буксира, время
      стыковки, исходы вылетов.
- [ ] Кадр стиля собран в движке.

**Гейт 1 — плейтест 3–5 человек со стороны:**
- [ ] Большинство сами лавируют (а не пробиваются форсажем); доля топлива на
      форсаж < 30–40%.
- [ ] После 2–3 вылетов сами оставляют запас на подъём.
- [ ] Просят ещё вылет.
- [ ] Стыковка < 15–20 секунд и воспринимается как выдох.
- [ ] Пресеты гравитации сравнены по протоколу
      [prototype-tech.md](prototype-tech.md) (слепо, 2–3 пресета из П1, П2, П4, по
      2 вылета, анкета 1–5); победитель выбран по критериям (читаемость ≥ 4 →
      меньше форсажа → честность ≥ 4, D35); если ни один не прошёл
      читаемость — сигнал гейта. Кривая и вариант трюма записаны в decisions.md.
- [ ] Записано, замечают ли звук раньше картинки.
- [ ] Анкета: «понятно ли по экрану, хватит ли топлива вернуться?» — ответ
      записан.
- [ ] Новичок справляется со связкой «поворот + тяга»; случайных нажатий сброса
      и буксира нет; записано, отключают ли автомасштаб и какая доля топлива
      уходит на тормоз.

**Если гейт не пройден — стоп.** Пересмотреть концепцию: без гравитации у игры
нет уникальной механики.

## Этап 2. Подготовка к срезу (1–2 недели)

**Работы:**
- симулятор экономики — Python, ≈ неделя ([econ-sim.md](econ-sim.md));
- валидатор генерации на симуляции траектории.

**DoD — симулятор** (цели и источники — таблица в [econ-sim.md](econ-sim.md)):
- [ ] Общий JSON параметров экономики читают и симулятор, и Godot (`Tuning`);
      тест сверки формулы потенциала с `GravityField` проходит.
- [ ] Эталонные вылеты — регрессионные тесты; все выполнимы (нет флагов
      «невыполнимо»); перекалиброваны под лестницу из потенциала (D30), вылет
      вниз на «Рабочем» окупается.
- [ ] Время до «Рабочего» ≤ 45 мин.
- [ ] Время до финала 8–12 ч (медиана + p10–p90).
- [ ] Восстановление после худшего случая (гибель на «Рабочем» + долг за аванс)
      ≤ 3–4 ледяных вылета.
- [ ] Ожидаемый доход низ > середина при 10–20% гибели внизу.
- [ ] Доля сожжённой добавки 30–60%.
- [ ] Добор обычных ресурсов на деталь Отрыва ≤ 4–6 вылетов.
- [ ] O37: «Рабочий» выгоднее шлюпки вскоре после покупки.
- [ ] «Горн» ×1,6: окупается с апгрейдами, не на базовом «Рабочем».
- [ ] Худший ремонт деталей Отрыва ≤ интервала хорошего окна (O51).
- [ ] Стратегия «Спокойный» доходит до финала.
- [ ] Чувствительность ±20% по каждому параметру, «торнадо»; отчёт в
      `docs/research/`.
- [ ] Числа баланса для среза записаны в economy.md (как стартовые).

**DoD — валидатор:**
- [ ] Валидатор (геометрическая проверка генератора) отбраковывает вырожденные
      генерации; на серии сгенерированных вылетов нет непроходимых.

## Этап 3. Вертикальный срез (10–14 недель) → гейт 2

**Работы:** всё из раздела «Вертикальный срез» в [scope.md](scope.md).
**В середине этапа** (когда кадр стиля и полёт выглядят хорошо) — страница в Steam:
капсула из кадра игры, 2–3 гифки с изолиниями, взнос Steam Direct.

**DoD (технический):**
- [ ] Полный цикл матка → вылет → матка на «Ободе» со всеми системами среза.
- [ ] Первые смены идут на верхнем ярусе «Обода» с переопределениями генератора
      (прибытие далеко от лун, лёд рядом, путь к матке свободен).
- [ ] HUD среза: значки буксира и стабильной орбиты, строка контракта, стрелки
      обломков, кольцо сканера, режим без интерфейса, узоры для дальтоников.
- [ ] Генератор среза: полный этап 7 (мелкие объекты), кометы,
      обломки игрока; ресурсная и траекторная проверка с запасным зерном;
      статистика для симулятора ([well-generator.md](well-generator.md)).
- [ ] Первые смены онбординга проходятся без подсказок разработчика.
- [ ] Граница буксира: предупреждение (визуально + звук) на низе среднего яруса;
      ниже буксир не вызывается; гибель шлюпки — груз изъят, обломков нет,
      письмо-выговор.
- [ ] Завязка работает: приветственная записка и первый наряд в почте; брезент с
      подсказкой при наведении; демонтаж с нелепой ценой; напоминания
      «мусор не убран» без штрафа.
- [ ] Загадка уникальной руды: добывается, хранится на складе, не продаётся;
      письмо «Неизвестный материал…»; строка о сходстве в подсказке брезента.
- [ ] Сохранение прогресса между сессиями.
- [ ] Страница Steam опубликована («скоро выйдет»).

**Гейт 2 — плейтест 10–20 человек** (закрытый плейтест Steam или Discord):
- [ ] Игроки проходят 5+ вылетов подряд.
- [ ] После гибели большинство сразу начинает новый вылет.
- [ ] Доля сжигаемой добавки 30–60%.
- [ ] Время до первой стыковки у новичка < 5 минут.
- [ ] Принято и записано решение по пиратам для EA.
- [ ] Вишлисты растут после публикации страницы.

## Этап 5. Early Access — глава 1 (5–7 месяцев)

**Работы:** всё из раздела «Early Access» в [scope.md](scope.md).

**DoD:**
- [ ] 3 планеты («Иней», «Обод», «Горн») с разными константами, карта системы, Отрыв проходим от начала до
      конца.
- [ ] 4 типа контрактов, 4 корабля (шлюпка, «Рабочий», грузовой, разведчик), 12–15 апгрейдов, 3 апгрейда хаба (сканер прибытия, своя переработка, склад обломков).
- [ ] Нарисованная сцена ангара, корабль для отрыва собирается на глазах.
- [ ] Генератор EA: константы трёх планет, обломки предшественника, щели в
      кольцах.
- [ ] Стапель: три детали по рецептам, рецепты видны с находки чертежа; склад
      ресурсов без лимита.
- [ ] Отрыв: сцена системы, маршрут через три планеты и корону, индикатор окна,
      ускорение времени ×1/×4 (V / крестовина вверх) со сбросом перед
      сближением, длительность 4–6 мин.
- [ ] Симуляция маршрута на панели Отрыва: точки манёвров; при идеальном
      исполнении план совпадает с полётом; в полёте видно расхождение с планом.
- [ ] Провал Отрыва: детали повреждаются (не теряются), экран провала с процентом
      повреждения, ремонт без уникальной руды ≤ ~4 вылета.
- [ ] Обломки предшественника на месте и не сгорают; чертёж и записи находятся в них.
- [ ] Тема хаба и трек Отрыва.
- [ ] HUD EA: интерфейс Отрыва (точки манёвров, состояние деталей, нагрев
      радиаторов), масштаб интерфейса.
- [ ] Сохранения, настройки, геймпад, проверка на Steam Deck, английский и русский.
- [ ] Раскрытие ИИ на странице Steam заполнено.
- [ ] Плейтест полного прохождения: хотя бы несколько человек дошли до Отрыва.
- [ ] Билд EA выпущен.
