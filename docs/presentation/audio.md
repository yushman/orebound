# Звук и музыка

Термины — [../glossary.md](../glossary.md).

## Задачи

1. **Тепло**, которого нет в схематичной картинке ([visual-style.md](visual-style.md)).
2. **Читаемость состояния:** масса, топливо, атмосфера, запас возврата — вторая
   линия против главного риска.
3. **Кривая вылета** «тишина → давление → выход» без интерфейса.

## Принцип: звук через корпус

В космосе звука нет. Игрок слышит то, что слышно **внутри шлюпки**: гул двигателя,
скрип корпуса, удары по обшивке, щелчки приборов. Продолжение образа
навигационного прибора; так сделано в Shipbreaker и Outer Wilds.

## Музыка по глубине

Музыка собирается из слоёв; громкость слоёв зависит от глубины (возможно, ещё от
загрузки трюма):

| Где | Что звучит |
|---|---|
| Верхний ярус | почти тишина: фон, гул бура, редкие ноты |
| Средний ярус | добавляется пульс, медленный ритм |
| Нижний ярус, дно | низкий гул, напряжение |
| Атмосфера | музыку глушит, треск и шипение |
| Подъём с грузом | слои затихают — выдох |
| Стыковка | тёплый аккорд — «дома» |

Жадность игрока слышна. Тишина наверху — содержание медитативной части.

**Хаб — единственное место с мелодией** (тёплая тема ангара, гул матки, далёкие
голоса, радио). **Отрыв** — второй полноценный трек: на выходе за край системы слои
собираются в полный трек ([../design/endgame.md](../design/endgame.md)). Во время
Отрыва звук приборов сообщает о перегреве и ударах — причине повреждения деталей.

## Звук как прибор

| Состояние | Звук |
|---|---|
| Масса груза | двигатель ниже и натужнее |
| Перегрев двигателя | гул грубее и натужнее; у порога — щелчок прибора; падение тяги слышно |
| Запас возврата | спокойный щелчок → двойной сигнал → непрерывный тон |
| Атмосфера | скрип корпуса, шипение, треск на каждом тике урона |
| Граница буксира | предупреждающий сигнал приборов при приближении и пересечении |
| Мелкий объект рядом | короткий сигнал с направлением в стерео |
| Форсаж | отчётливый рёв |
| Переработка | спокойный механический гул |
| Стыковка | крупный приятный лязг замков |
| Наполнение трюма | глухой стук ячейки |
| Обломки | радиомаяк, слабеющий по мере сгорания |
| Почта | печатная машинка, удар печати |

Правило: **каждое критичное состояние имеет звук**. Предупреждения редкие и тихие,
громкость растёт только при реальной опасности. Напряжение передаётся тембром, а
не громкостью (без скримеров).

## Производство одним человеком

**Эффекты:**
- бесплатные библиотеки: Freesound (CC0), ежегодные бесплатные паки Sonniss;
- своя запись на телефон (металл, шипение чайника, удары по кастрюле) + обработка;
- зацикленные звуки с изменением высоты и фильтра в реальном времени (тяга,
  масса); полноценный синтез в реальном времени не нужен;
- недорогой звуковой редактор (Reaper).

**Музыка:**
- **космос:** генеративный фон в игре — сэмплы случайно в пределах лада (пример
  принципа — Mini Metro); разные лады для разных планет («Иней», «Обод», «Горн» — [../design/planets.md](../design/planets.md));
- **хаб и Отрыв:** два мелодичных трека — заказ композитору, если есть бюджет
  (лучшее вложение в звук); иначе своё или библиотека как временное решение.

## Скоуп по этапам

- **Прототип:** гул двигателя по массе, шипение атмосферы и тики урона, сигналы
  запаса возврата. Вопрос: реагирует ли игрок на звук раньше картинки.
- **Срез:** генеративный фон со слоями по глубине, фон хаба, стыковка, почта,
  временная мелодия хаба.
- **EA:** тема хаба и трек Отрыва, варианты фона для планет, полный набор звуков
  приборов.

## Риски

1. **Звук затягивает** — ограничение по времени: сначала функциональные звуки.
2. **Генеративная музыка скучна** — вариации, лады по планетам.
3. **Перепады громкости** — узкий диапазон, тембр вместо громкости.

## Отклонённые варианты

- **«Космические» звуки снаружи корабля** — теряется образ кабины и прибора.
- **Музыка по событиям (боевая/спокойная)** — заменена слоями по глубине.
- **Нейросетевая музыка (Suno, Udio)** — лицензионные риски, раскрытие ИИ,
  враждебность аудитории, трудно получить слои.
- **Библиотеки фоновой музыки как основа** — безлико.
- **Полный синтез звука в реальном времени** — лишняя глубина для одного человека.
