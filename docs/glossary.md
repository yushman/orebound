# Глоссарий

Единые термины для всех документов. Если термин здесь есть — в других документах
используется именно он.

| Термин | Значение | Подробно |
|---|---|---|
| **Матка** | Корпоративный корабль-носитель, он же хаб. Прыгает к выбранной планете, висит на высокой орбите над колодцем; из её ангара вылетает игрок | [hub.md](design/hub.md) |
| **Колодец** | Гравитационный колодец планеты — пространство вылета вокруг неё. Чем ближе к планете, тем сильнее притяжение | [gravity-well.md](design/gravity-well.md) |
| **«Иней», «Обод», «Горн»** | Три планеты главы 1 (рабочие названия): внешняя стартовая (EA), средняя эталонная (планета среза и демо), внутренняя тяжёлая | [planets.md](design/planets.md) |
| **Гравитация планеты** | Полный перепад потенциала планеты относительно «Обода» (×1,0); вместе с долями ярусов задаёт лестницу цены подъёма | [planets.md](design/planets.md) |
| **Ярус** | Полоса колодца по уровню потенциала (доля перепада от кромки атмосферы до орбиты матки); смысл — цена подъёма отсюда. Четыре яруса: **верхний, средний, нижний, дно**. Под дном — атмосфера | [gravity-well.md](design/gravity-well.md) |
| **Дно** | Самый глубокий ярус у кромки атмосферы. Здесь уникальная руда | [gravity-well.md](design/gravity-well.md) |
| **Атмосфера** | Слой у планеты ниже дна. Ресурсов нет, тикающий урон и торможение. Цена ошибки в манёвре | [flight.md](design/flight.md) |
| **Лёд** | Ресурс верхнего яруса, сырьё для топлива. Объёмный, лёгкий. Сам по себе тоже горит как топливо, но неэффективно | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Топливная ячейка** | Сжатое топливо после переработки льда. Компактная: 1 ячейка трюма, масса 3, энергия 3 (гипотеза) | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Переработка** | Сжатие льда в топливные ячейки. Меняет только объём (3 льда + 1 добавка → 1 ячейка); масса и энергия топлива сохраняются, добавка сгорает | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Добавка** | Руда среднего тира, сжигаемая при переработке на корабле | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Переработчик** | Модуль корабля для переработки в вылете. Занимает место в трюме, открывается апгрейдом | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Трюм** | Единое хранилище корабля: и груз, и топливо | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Запас возврата** | Хватит ли топлива подняться отсюда к матке с текущим грузом. Показывается траекторией подъёма: обычная → жёлтая → красная | [flight.md](design/flight.md) |
| **Форсаж** | Режим тяги на пробел: быстрее, но в 3–4 раза дороже по топливу на тот же прирост скорости | [flight.md](design/flight.md) |
| **Тормоз** | Тормозные двигатели: гасят скорость относительно ориентира; слабее главного и дороже по топливу | [controls.md](design/controls.md) |
| **Ориентир тормоза** | Объект, относительно которого гасится скорость (астероид, глыба кольца, обломки, матка); если рядом ничего нет — круговая орбита на текущей высоте. Помечается на экране | [controls.md](design/controls.md) |
| **Аварийный сброс** | Сброс груза долгим нажатием, с самого тяжёлого; топливо не трогает | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Сканер** | Импульс в вылете (C / Y): на несколько секунд ярче изолинии и подсвечена руда в радиусе; бесплатно, с перезарядкой | [controls.md](design/controls.md) |
| **Сканер прибытия** | Апгрейд хаба: перед прыжком видна примерная картина, улучшенный даёт выбрать точку прибытия. Не путать со сканером | [hub.md](design/hub.md) |
| **Полная траектория** | Траектория полёта целиком, по удержанию Shift / нажатию на левый стик | [controls.md](design/controls.md) |
| **Инструмент** | Единственный «ствол» корабля, два режима: **луч** (добыча) и **импульс** (разбить или отбросить мелкий объект) | [flight.md](design/flight.md) |
| **Стабильная орбита** | Движение без тяги; топливо не тратится. Только на ней работает переработчик | [flight.md](design/flight.md) |
| **Буксир** | Спасение службой матки. Базово только до низа среднего яруса, для всех кораблей (ниже — разовый глубокий буксир); стоит платы и конфискации части груза | [failure.md](design/failure.md) |
| **Разовый глубокий буксир** | Расходник из хаба: один вызов буксира в нижнем ярусе или на дне (не в атмосфере); потрачен — покупается заново; служебной шлюпке недоступен | [failure.md](design/failure.md) |
| **Граница буксира** | Низ среднего яруса — ниже буксир не вызывается ни для кого без разового глубокого буксира. Фиксирована; показывается особой изолинией; на ней обязательное предупреждение | [failure.md](design/failure.md) |
| **Обломки** | Остатки погибшего собственного корабля с частью груза (служебная шлюпка обломков не оставляет). Остаются на своей орбите, их можно забрать; орбита снижается, в атмосфере обломки сгорают | [failure.md](design/failure.md) |
| **Служебная шлюпка** | Корабль корпорации: стартовый корабль новичка и бесплатный запасной при нехватке денег на ремонт. Не может спуститься ниже среднего яруса — граница задаётся тягой, а не топливом; 2 ячейки топлива на вылет бесплатно | [failure.md](design/failure.md) |
| **«Рабочий»** | Первый свой корабль, 400 кр (гипотеза); открывает нижний ярус и дно; переработчик — модуль-апгрейд | [economy.md](design/economy.md) |
| **Контракт** | Заказ корпорации на вылет. Типы: **заказ**, **подработка**, **доставка вниз**, **маяк** | [contracts.md](design/contracts.md) |
| **Аванс** | Топливные ячейки, выданные под контракт. При невыполнении — долг за потраченное | [contracts.md](design/contracts.md) |
| **Ресурсы** | Валюта трюма: всё, что добыто и лежит в корабле. Под риском | [economy.md](design/economy.md) |
| **Кредиты** | Валюта банка: деньги на счету. В безопасности | [economy.md](design/economy.md) |
| **Ангар / Контора / Пульт вылета** | Три экрана хаба | [hub.md](design/hub.md) |
| **Почта** | Канал корпоративных сообщений: инструктаж, счета, новости. Основной носитель юмора и мира | [hub.md](design/hub.md) |
| **Отрыв** | Финал главы: вылет на корабле для отрыва из гравитации звезды — падение к звезде и импульс у короны (эффект Оберта) после манёвров у «Обода» и «Горна» | [endgame.md](design/endgame.md) |
| **Предшественник** | Прежний владелец места игрока в ангаре; погиб, пытаясь совершить Отрыв | [endgame.md](design/endgame.md) |
| **Обломки предшественника** | Постоянный сюжетный объект на малой луне нижнего яруса; не сгорают; в них чертёж и записи | [endgame.md](design/endgame.md) |
| **Брезент** | «Мусор предыдущего владельца» в углу ангара — недостроенный корабль предшественника | [hub.md](design/hub.md) |
| **Задолженность** | Сюжетный долг игрока перед корпорацией; фоновая цифра в почте, без выплат. Не путать с долгом за аванс | [onboarding.md](design/onboarding.md) |
| **Корабль для отрыва** | Корабль, который собирается на стапеле в ангаре матки из трёх деталей | [endgame.md](design/endgame.md) |
| **Стапель** | Место в углу ангара (под бывшим брезентом), где уникальная руда за один шаг превращается в деталь корабля для отрыва | [endgame.md](design/endgame.md) |
| **Детали корабля для отрыва** | Радиаторы («Иней»), Каркас («Обод»), Двигатель отрыва («Горн»); рецепт = уникальная руда + обычная руда своей планеты + кредиты | [endgame.md](design/endgame.md) |
| **Склад** | Хранилище ресурсов в хабе, без лимита | [hub.md](design/hub.md) |
| **Окно отрыва** | Удачное расположение планет для Отрыва; система сдвигается с каждым вылетом. Показывается на карте системы | [endgame.md](design/endgame.md) |
| **Сцена системы** | Сцена Отрыва в масштабе системы (часть режима «карта системы»): точечные массы, корона, ускорение времени ×1/×4 |
| **Симуляция маршрута** | Расчёт идеального маршрута Отрыва для текущего окна с точками манёвров; в полёте — план на траектории | [endgame.md](design/endgame.md) | [endgame.md](design/endgame.md) |
| **Глава** | Одна звёздная система с маткой и Отрывом в конце. В EA — одна глава | [endgame.md](design/endgame.md) |
| **Смена** | Один из первых обучающих вылетов на служебной шлюпке | [onboarding.md](design/onboarding.md) |
| **Пресет гравитации** | Вариант кривой притяжения g(r) = k·M / (r^p + ε) для сравнения в прототипе: П1 «Ньютон», П2 «Плоский 2D», П3 «Компромисс», П4 «Смешанный» | [prototype-tech.md](production/prototype-tech.md) |
| **Полоса энергии** | Элемент HUD: энергия топлива с отметкой «нужно на подъём отсюда»; экранная пара к линии запаса возврата | [hud.md](design/hud.md) |
| **Шкала колодца** | Вертикальная шкала HUD: ярусы сегментами пропорционально долям перепада потенциала, матка, кромка атмосферы, граница буксира, корабль | [hud.md](design/hud.md) |
| **Изолинии** | Линии равного гравитационного потенциала — основа визуального стиля | [visual-style.md](presentation/visual-style.md) |
| **Симулятор экономики** | Python-инструмент этапа 2: калькулятор вылета, модель исхода, стратегии, Монте-Карло; общий JSON параметров с Godot | [econ-sim.md](production/econ-sim.md) |
| **Генератор колодца** | Чистая функция (константы планеты, зерно, номер вылета) → картина вылета; всё на заданных орбитах; проверка в три уровня | [well-generator.md](production/well-generator.md) |
| **Запасное зерно** | Заранее проверенное зерно, если новые не прошли проверку за N попыток | [well-generator.md](production/well-generator.md) |

## Отклонённые термины

| Не используем | Используем |
|---|---|
| хаб-планета, станция | матка |
| майнер-тул, оружие | инструмент (луч / импульс) |
| open run / contract run | вылет (с контрактом или без) |
| бак (как отдельная ёмкость) | трюм |
| уравнивание скорости (отдельное действие), задний ход | тормоз |
| катализатор | добавка |
| экстракшн-рогалик (как ярлык) | см. [presentation/positioning.md](presentation/positioning.md) |
| освоение системы | сборка корабля для отрыва |
| трос, граница троса, длина троса | граница буксира |
