# Глоссарий

Единые термины для всех документов. Если термин здесь есть — в других документах
используется именно он.

| Термин | Значение | Подробно |
|---|---|---|
| **Матка** | Корпоративный корабль-носитель, он же хаб. Прыгает к выбранной планете, висит на геостационарной орбите — гребне эффективного потенциала (угловая скорость Ω_f); вылет показан во вращающейся с ней системе, в кадре она неподвижна. Из её ангара вылетает игрок | [hub.md](design/hub.md) |
| **Колодец** | Гравитационный колодец планеты — пространство вылета ниже матки, до кромки атмосферы. Чем ближе к планете, тем сильнее притяжение | [gravity-well.md](design/gravity-well.md) |
| **Луны** | Спутники планеты; в вылете генерируются случайно (число, размер): крупные 1 000–2 000 ед. — высоко, чуть ниже матки; малые 300–700 ед. — низко. Очень крупные на дальних орбитах — только в сцене Отрыва и на карте системы (D35) | [flight.md](design/flight.md) |
| **Сектор** | Видимая и достижимая часть кольца у матки: в обе стороны вдоль кольца (≈ ±30–60° за вылет — гипотеза) и по вертикали от кромки атмосферы до потолка. Краёв нет: кольцо периодично, генерируется лениво угловыми чанками (D35) | [gravity-well.md](design/gravity-well.md) |
| **Дрейф** | Медленное движение вдоль сектора относительно матки на высоте r со скоростью (Ω(r) − Ω_f)·r: ниже матки — вперёд, тем быстрее, чем ниже; выше матки — назад. Двигаться с дрейфом своей глубины = стабильная орбита. **Дрейфовый коридор** — смена глубины, чтобы почти бесплатно проплыть вдоль сектора | [flight.md](design/flight.md) |
| **Потолок** | Граница на +5 000 ед. над маткой. Выше — тревога, через N секунд буксир в хаб со всеми последствиями буксира | [flight.md](design/flight.md) |
| **Местная вертикаль** | Камера вылета: «низ» экрана к центру планеты под кораблём, кромка планеты внизу | [controls.md](design/controls.md) |
| **«Иней», «Обод», «Горн»** | Три планеты главы 1 (рабочие названия): внешняя стартовая (EA), средняя эталонная (планета среза и демо), внутренняя тяжёлая | [planets.md](design/planets.md) |
| **Гравитация планеты** | Полный перепад потенциала планеты относительно «Обода» (×1,0); вместе с долями ярусов задаёт лестницу цены подъёма | [planets.md](design/planets.md) |
| **Ярус** | Полоса кольца колодца по уровню эффективного потенциала Φ_eff (доля перепада от кромки атмосферы до орбиты матки); смысл — цена подъёма отсюда. Четыре яруса: **верхний, средний, нижний, дно**. Под дном — атмосфера | [gravity-well.md](design/gravity-well.md) |
| **Дно** | Самый глубокий ярус у кромки атмосферы. Здесь уникальная руда | [gravity-well.md](design/gravity-well.md) |
| **Атмосфера** | Слой у планеты ниже дна. Ресурсов нет, тикающий урон и торможение. Цена ошибки в манёвре | [flight.md](design/flight.md) |
| **Лёд** | Ресурс верхнего яруса, сырьё для топлива. Объёмный, лёгкий. Сам по себе тоже горит как топливо, но неэффективно | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Топливная ячейка** | Сжатое топливо после переработки льда. Компактная: 1 ячейка трюма, масса 3, энергия 3 (гипотеза) | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Переработка** | Сжатие льда в топливные ячейки. Меняет только объём (3 льда + 1 добавка → 1 ячейка); масса и энергия топлива сохраняются, добавка сгорает | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Добавка** | Руда среднего тира, сжигаемая при переработке на корабле | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Переработчик** | Модуль корабля для переработки в вылете. Занимает место в трюме, открывается апгрейдом | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Трюм** | Единое хранилище корабля: и груз, и топливо | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Запас возврата** | Хватит ли топлива вернуться отсюда к матке с текущим грузом. Энергетическая оценка, не предсказанная траектория; показывается только цветом (обычная → жёлтая → красная): стрелка к матке за экраном, контур матки в кадре; при смене цвета — звук и короткий текст | [flight.md](design/flight.md) |
| **Короткая линия** | Предсказание полёта на ≈ 10–20 с вперёд тем же шагом, что полёт; единственная линия предсказания в вылете | [flight.md](design/flight.md) |
| **Форсаж** | Режим тяги на пробел: быстрее, но в 3–4 раза дороже по топливу на тот же прирост скорости; греет двигатель быстрее обычной тяги | [flight.md](design/flight.md) |
| **Перегрев** | Шкала нагрева главного двигателя и форсажа: растёт при тяге (форсаж — быстрее), без тяги остывает; выше порога тяга плавно падает, на 100% — минимум. Ничего не ломается; тормоз и синхронизация дрейфа не греют | [flight.md](design/flight.md) |
| **Мягкий тормоз** | S / LT: тяга между направлениями «против скорости» и «назад от носа» (максимум ≈ ⅓ главной — гипотеза): нос по ходу — гасит скорость, под 90° — сила ≈ 0,71, против скорости — ноль. Расход на Δv — как у главного двигателя; не греется. Бывший «мягкий реверс» | [controls.md](design/controls.md) |
| **Синхронизация дрейфа** | Shift / левый стик (зажать): гасит скорость относительно ориентира синхронизации; слабее главного двигателя и дороже по топливу. Бывший «тормоз» | [controls.md](design/controls.md) |
| **Ориентир синхронизации** | Ближайший интерактивный объект, с дрейфом которого уравнивается скорость (астероид, глыба кольца, обломки, матка); если рядом ничего нет — стабильная орбита на текущей высоте (дрейф своей полосы). Помечается на экране | [controls.md](design/controls.md) |
| **Аварийный сброс** | Сброс груза долгим нажатием, с самого тяжёлого; топливо не трогает | [hold-and-fuel.md](design/hold-and-fuel.md) |
| **Сканер** | Импульс в вылете (C / Y): на несколько секунд ярче ореолы лун и подсвечена руда в радиусе; бесплатно, с перезарядкой | [controls.md](design/controls.md) |
| **Сканер прибытия** | Апгрейд хаба: перед прыжком видна примерная картина, улучшенный даёт выбрать точку прибытия. Не путать со сканером | [hub.md](design/hub.md) |
| **Полная траектория** | Траектория полёта целиком; только в сцене Отрыва (в вылете снята, D35) | [controls.md](design/controls.md) |
| **Инструмент** | Единственный «ствол» корабля, две кнопки (D40): **луч** (лазер, разбивает объекты) и **сбор** (сектор перед прицелом, собирает куски) | [flight.md](design/flight.md) |
| **Стабильная орбита** | Движение без тяги со скоростью дрейфа своей глубины; топливо не тратится. Только на ней работает переработчик | [flight.md](design/flight.md) |
| **Буксир** | Спасение службой матки. Базово только до низа среднего яруса, для всех кораблей (ниже — разовый глубокий буксир); стоит платы и конфискации части груза | [failure.md](design/failure.md) |
| **Разовый глубокий буксир** | Расходник из хаба: один вызов буксира в нижнем ярусе или на дне (не в атмосфере); потрачен — покупается заново; служебной шлюпке недоступен | [failure.md](design/failure.md) |
| **Граница буксира** | Низ среднего яруса — ниже буксир не вызывается ни для кого без разового глубокого буксира. Фиксирована; показывается отдельной окружностью границы; на ней обязательное предупреждение | [failure.md](design/failure.md) |
| **Обломки** | Остатки погибшего собственного корабля с частью груза (служебная шлюпка обломков не оставляет). Остаются на своей орбите, их можно забрать; орбита снижается, в атмосфере обломки сгорают | [failure.md](design/failure.md) |
| **Служебная шлюпка** | Корабль корпорации: стартовый корабль новичка и бесплатный запасной при нехватке денег на ремонт. Ниже границы буксира — тревога и через N секунд принудительный буксир в хаб с изъятием всего груза и выговором (D35); 2 ячейки топлива на вылет бесплатно | [failure.md](design/failure.md) |
| **«Рабочий»** | Первый свой корабль, 400 кр (гипотеза); открывает нижний ярус и дно; переработчик — модуль-апгрейд | [economy.md](design/economy.md) |
| **Контракт** | Заказ корпорации на вылет. Типы: **заказ**, **подработка**, **доставка вниз**, **маяк** | [contracts.md](design/contracts.md) |
| **Аванс** | Топливные ячейки, выданные под контракт. При невыполнении — долг за потраченное | [contracts.md](design/contracts.md) |
| **Ресурсы** | Валюта трюма: всё, что добыто и лежит в корабле. Под риском | [economy.md](design/economy.md) |
| **Кредиты** | Валюта банка: деньги на счету. В безопасности | [economy.md](design/economy.md) |
| **Ангар / Контора / Пульт вылета** | Три экрана хаба | [hub.md](design/hub.md) |
| **Почта** | Канал корпоративных сообщений: инструктаж, счета, новости. Основной носитель юмора и мира | [hub.md](design/hub.md) |
| **Отрыв** | Финал главы: вылет на корабле для отрыва из гравитации звезды — падение к звезде и импульс у короны (эффект Оберта) после манёвров у «Обода» и «Горна». Отдельная сцена со своей физикой; маршрут пересматривается (D35, O72) | [endgame.md](design/endgame.md) |
| **Предшественник** | Прежний владелец места игрока в ангаре; погиб, пытаясь совершить Отрыв | [endgame.md](design/endgame.md) |
| **Обломки предшественника** | Постоянный сюжетный объект на малой луне нижнего яруса; не сгорают; в них чертёж и записи | [endgame.md](design/endgame.md) |
| **Брезент** | «Мусор предыдущего владельца» в углу ангара — недостроенный корабль предшественника | [hub.md](design/hub.md) |
| **Задолженность** | Сюжетный долг игрока перед корпорацией; фоновая цифра в почте, без выплат. Не путать с долгом за аванс | [onboarding.md](design/onboarding.md) |

## Отклонённые термины

| Не используем | Используем |
|---|---|
| хаб-планета, станция | матка |
| майнер-тул, оружие | инструмент (луч / сбор) |
| open run / contract run | вылет (с контрактом или без) |
| бак (как отдельная ёмкость) | трюм |
| уравнивание скорости (отдельное действие) | синхронизация дрейфа |
| тормоз относительно ориентира, ориентир тормоза | синхронизация дрейфа, ориентир синхронизации |
| мягкий реверс (чистая тяга против носа) | мягкий тормоз |
| катализатор | добавка |
| экстракшн-рогалик (как ярлык) | см. [presentation/positioning.md](presentation/positioning.md) |
| освоение системы | сборка корабля для отрыва |
| трос, граница троса, длина троса | граница буксира |
