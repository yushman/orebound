# gen

Pure static generators for the well; no node state, no cache.

- `WellGenerator.tiers() -> Dictionary` is stage 1. It reads `Tuning.field` and `Tuning.planet` on every call and root-finds on `GravityField.planet_potential_eff`. Result: `boundaries: Array[float]` (5 ascending radii: `atmosphere_edge`, then 10 %, 35 %, 75 % of the Φ_eff swing above the edge, then `carrier_orbit_radius`; cumulative `tier_shares` from the bottom), `tow` (= `boundaries[2]`, bottom of the middle tier) and `ceiling` (= `carrier_orbit_radius + ceiling_offset`).
- swing = Φp(`carrier_orbit_radius`) − Φp(`atmosphere_edge`); each inner boundary is found by bisection on [edge, r_c] and stops on a Φ tolerance relative to the swing, not an r tolerance: `frame_omega` uses `eps` while Φ does not, so g_eff(r_c) is only ≈ 0 and the profile is flat near r_c.
- `WellGenerator.picture(seed, flight) -> Dictionary` (`{seed, flight, moons: Array[BodyParams]}`) builds the moons. `_build(seed, flight)` (static, test-visible) seeds a `RandomNumberGenerator` with `hash([seed, flight])`, so a picture is deterministic and the same call gives the same result. Moon count is `randi_range(moon_count_min, moon_count_max)` (at least 1): one large moon (`radius` in `moon_large_radius_min/max`, orbit between `boundaries[3]` and `boundaries[4]`) and the rest small (`moon_small_radius_min/max`, orbit between `boundaries[1]` and `boundaries[3]`). Each moon has `parent` 0, p = 2, random `phase`, `mass = moon_mass_k · radius^moon_mass_exp`, `influence_radius = moon_influence_k · radius` and `angular_speed` of a circular orbit on the planet pull at its orbit radius (`accel_of(0, ...)`).
- `WellGenerator.check(moons) -> bool` accepts a layout when every moon clears the atmosphere (`orbit_radius − radius > atmosphere_edge`), the carrier orbit (`|r_c − orbit_radius| > influence_radius + moon_margin`) and every other moon (orbit gap > sum of influence radii + `moon_margin`). `picture` tries `seed`, `seed + 1`, ... up to `max_tries` and returns the first layout passing `check`; if none passes it builds `fallback_seed` (it is not checked again; a test pins that `fallback_seed` 1 passes on the default field and p1..p4). The returned `seed` is the seed actually used, so it may differ from the requested one.
