# ui

Screen-space Control scenes.

- `HUD.tscn` is an empty Control root.
- `TuningPanel.tscn` is a dev-only Control root with `TuningPanel.gd`, instanced under a `CanvasLayer` in `Run.tscn`; hidden by default, `debug_tuning_panel` (F1) toggles it in `_unhandled_input` and marks the event handled.
- Header: an `OptionButton` with the full preset names (same as the `name` in `p1`..`p4.tres`; P4 selected on start), Load and Save. Load applies `Tuning.load_preset(<presets_dir>/pN.tres)` via `Tuning.apply`; Save overwrites the selected preset with `Tuning.save_preset` at `<presets_dir>/pN.tres` (`presets_dir` defaults to `res://presets`, a dev tool run from the editor; there is no `user://` save and no save-as). A failed load or save is a `push_error`.
- Slider rows (Label + `HSlider` + value Label) are built in code from the `ROWS` descriptor list (target `"field"` | `"ship"` | `"planet"` | `"view"` | body index, property, min, max, step). Covered: field `k`, `eps`, `fade_width` (min 0.01: `_fade` divides by it); per body `p` and `mass`, moon `influence_radius`; ship thrust, boost, brake, fuel, thrust ramp (`ramp_time`, `ramp_min_fraction`), heat, sync prediction (`predict_every`, `predict_short_steps`) and `hull_max` parameters; planet `atmosphere_drag`, `atmosphere_damage`, `density_shape` (ids `planet.<prop>`, written into `Tuning.planet`); view `halo_alpha` (0..1), `ring_count` (1..12, int), `ring_period` (0.2..10), `ring_px` (0.5..5), `ring_alpha` (0..1) (ids `view.<prop>`, written into `Tuning.view`). Not sliders (pinned by a negative test): orbit parameters, the D35 radii and `sync_radius` (preset constants), `turn_accel`, `spin_damping`, `heading_gain`; Ω_f is derived. `sliders` maps ids like `field.k`, `body1.mass`, `ship.thrust_accel` to the slider.
- Ranges fit the D35 scale (mass 1..2e7 with `exp_edit`, `influence_radius` 0..20000, `thrust_accel` / `brake_accel` 0..50, fractions 0..1, `predict_every` min 1, `predict_short_steps` 300..1800); code defaults of `Tuning.ship`, `Tuning.planet` and `Tuning.view` must lie inside them (test).
- A slider change writes straight into the current `Tuning.field` / `Tuning.ship` / `Tuning.planet` / `Tuning.view` / `Tuning.field.bodies[i]` (looked up on every change, never cached; int properties get `int(v)`), so the next `GravityField.accel` / `ShipFlight.step` / Prediction call sees it. Slider changes do not respawn the ship.
- On `Tuning.preset_applied` (and in `_ready`) `_sync` sets every slider from the current `Tuning` without emitting `value_changed`, so syncing never writes back; values outside a slider's range are kept as is. Rows of bodies with index >= `Tuning.field.bodies.size()` are hidden and skipped (the default D35 field has one body), and come back with a multi-body preset.
- Every panel control has `focus_mode = FOCUS_NONE` (mouse only), so flight keys never reach it and flight input stays live while the panel is open.
- A readout `Label` at the top of the panel is refreshed in `_process` while the panel is visible: ship hull, `ShipFlight.atmosphere_density` at the ship and `Telemetry.crashes`. The Ship node is found at `../../Ship` (or set via `ship`); without one only the crash count is shown.
